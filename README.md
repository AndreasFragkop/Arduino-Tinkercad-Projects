# Arduino-Tinkercad-Projects

Hello everyone, in this repository I store all the Arduino projects that I create and simulate using [Tinkercad Circuits](https://www.tinkercad.com/circuits). These projects are designed to explore Arduino programming, electronics, and circuit design. This repository is aimed at students, hobbyists, and anyone who wants to learn Arduino through practical simulation projects.

![Arduino Uno](Logo.Webp)

---

## 🔧 What’s Inside

This repository contains multiple Arduino projects, each organized in its own folder with the required files and project details.

- Circuit image (.png)
- Arduino code (.ino)
- Components list (.csv)
- Description (.md)
- Schematic view (.pdf)

---

## 📂 Project List

| Project | Description |
|---------|-------------|
| [Arduino 16x2 LCD Interface](https://github.com/AndreasFragkop/Arduino-Tinkercad-Projects/tree/main/Arduino%2016x2%20LCD%20Interface) | A scrolling text display that shows “Loading Data” on a 16x2 LCD, with a potentiometer to adjust the contrast. |
| [Arduino Blink LED Circuit](https://github.com/AndreasFragkop/Arduino-Tinkercad-Projects/tree/main/Arduino%20Blink%20LED%20Circuit) | A simple circuit that turns a red LED on and off at one-second intervals to create a steady blinking effect. |
| [Arduino Multi-Tasking LED Controller](https://github.com/AndreasFragkop/Arduino-Tinkercad-Projects/tree/main/Arduino%20Multi-Tasking%20LED%20Controller) | A circuit that blinks a blue LED automatically while a push button independently controls a green LED. |
| [Arduino Piano](https://github.com/AndreasFragkop/Arduino-Tinkercad-Projects/tree/main/Arduino%20Piano) | A small digital piano built with Arduino where buttons act as keys to play musical notes. |
| [Arduino Traffic Light Simulator](https://github.com/AndreasFragkop/Arduino-Tinkercad-Projects/tree/main/Arduino%20Traffic%20Light%20Simulator) | A traffic light simulation that cycles through red, green, and yellow LEDs at timed intervals. |
| [Digital Thermometer with LCD Display](https://github.com/AndreasFragkop/Arduino-Tinkercad-Projects/tree/main/Digital%20Thermometer%20with%20LCD%20Display) | A digital thermometer that measures temperature with a TMP36 sensor and displays the result on a 16x2 LCD. |
| [Multi-LED Digital Controller with On-Off Switch](https://github.com/AndreasFragkop/Arduino-Tinkercad-Projects/tree/main/Multi-LED%20Digital%20Controller%20with%20On-Off%20Switch) | A circuit that controls multiple LEDs with a switch to produce a back-and-forth scanning light effect. |
| [Push Button LED Controller](https://github.com/AndreasFragkop/Arduino-Tinkercad-Projects/tree/main/Push%20Button%20LED%20Controller) | A simple circuit where a push button controls the turning on and off of an LED. |
| [Smart Night Light](https://github.com/AndreasFragkop/Arduino-Tinkercad-Projects/tree/main/Smart%20Night%20Light) | An automatic lighting system that uses a photoresistor to turn an LED on in dark conditions and off in brighter conditions. |
| [Solar Tracking System Using LDR Sensors](https://github.com/AndreasFragkop/Arduino-Tinkercad-Projects/tree/main/Solar%20Tracking%20System%20Using%20LDR%20Sensors) | A simple system that uses LDR sensors to detect and follow the strongest light source. |

More projects will be added over time.
